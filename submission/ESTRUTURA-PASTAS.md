# Estrutura sugerida de entrega

```text
entrega/
  backend/
    wtc-connect-api.zip
  app/
    wtc-connect-app.zip
    app-release.apk
  apresentacao/
    apresentacao-sprint2.pptx
    apresentacao-sprint2.pdf
  docs/
    sprint2-adequacao.md
    sprint2-backend-especificacao.md
    roteiro-apresentacao-sprint2.md
```

## Conteudo recomendado

- `backend/`: projeto ASP.NET Core completo, sem segredos reais, com README.
- `app/`: projeto Android completo e o APK gerado para avaliação.
- `apresentacao/`: versão editável e exportada em PDF.
- `docs/`: apoio interno para o time e base da apresentação.
